# 🎓 Learnova BD - Course Directory & Affiliate Hub

A fast, mobile-first web app designed for affiliate marketing teams and students to easily search, browse, and share 10 Minute School courses with promo-attached affiliate links.

---

## 🌟 Key Features

### 👥 1. Teammate Mode (Internal Sales Tool)
- **Instant Search:** Fast keyword search across courses, categories, and promo codes.
- **1-Tap Message Copy:** Generates pre-written, student-ready sales pitches in Bengali with course title, discount price, promo code, and link.
- **1-Tap Link Copy:** Copies direct affiliate URLs.
- **Financial Insights:** Real-time visibility on 15% commission, suggested cashback, and net profit per course.
- **Direct Share:** 1-click sharing to WhatsApp and Messenger.

### 🎓 2. Student Mode (Public Course Showcase)
- **Modern Course Catalog:** Clean visual cards with discount badges.
- **Category Filters:** Class 6-10 Batches, SSC, HSC 26, HSC 27, University & Medical Admission, Spoken English & IELTS, Skills & Freelancing, Job Prep, and Islamic Studies.
- **Direct Enrollment:** Direct call-to-action buttons redirecting through affiliate links.

### ⚙️ 3. Manager / Admin Dashboard
- **Add / Edit Courses:** Full CRUD modal to add new courses or adjust prices, promo codes, and affiliate links visually.
- **Google Sheets Sync:** Paste published Google Sheet CSV link for live auto-updating.
- **Export & Backup:** 1-click download in CSV and JSON formats.

## 🚀 Deployment

### Option A: Deploy on Vercel (Recommended)
1. Push this repository to GitHub.
2. In [Vercel Dashboard](https://vercel.com/dashboard), click **Add New ➡️ Project**.
3. Select your GitHub repository and click **Deploy**.

### Option B: Deploy on Netlify
1. Drag and drop the root folder into [Netlify Drop](https://app.netlify.com/drop).
2. Get your free live URL immediately.

---

## 📱 Mobile App Usage (PWA)
1. Open the live URL on your phone browser (Chrome on Android or Safari on iOS).
2. Tap menu ➡️ **Add to Home Screen**.
3. Use it like a native mobile app anytime!
